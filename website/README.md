# Moadhn App Website

This is a marketing website for the Moadhn application, built with React, Vite, and Tailwind CSS.
Supports Dark Mode and Arabic (RTL).

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Fonts

Uses `Tajawal` from Google Fonts.

## Icons

Uses `lucide-react`.
